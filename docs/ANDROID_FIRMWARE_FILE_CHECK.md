# Android: выбор и первичная проверка файла

В Android-приложении появился пункт «Выбрать файл прошивки и проверить».

## Что делает функция

1. Открывает системный выбор файла Android.
2. Принимает файл из выбранного пользователем хранилища.
3. Ограничивает размер копирования 64 МБ.
4. Проверяет расширение: BIN, HEX или MOT.
5. Считает SHA-256 и показывает имя, размер и хеш.
6. Удаляет временную копию из кеша после проверки.

## Чего функция НЕ делает

- Не определяет, подходит ли файл конкретному ЭБУ.
- Не проверяет фирменную контрольную сумму производителя.
- Не расшифровывает и не анализирует структуру прошивки.
- Не подключается к Scanmatik.
- Не читает, не стирает и не записывает память ЭБУ.

SHA-256 помогает сравнить целостность двух копий одного файла. Он не доказывает, что файл безопасен или подходит автомобилю.

## Текущая диагностика

Экран Bluetooth по-прежнему использует ELM327-совместимый протокол для стандартных OBD-II параметров и кодов неисправностей. Это не является поддержкой Scanmatik. Для Scanmatik необходима проверенная документация производителя и подтверждение поддержки конкретного адаптера на Android.

## Проверка перед программированием

До реализации записи требуются точные идентификаторы ЭБУ (HW/SW/calibration), подтверждённый протокол и формат файла, правила проверки контрольных сумм, резервная копия оригинального содержимого, испытанная процедура восстановления и стабильное питание. До выполнения этих условий запись остаётся отключённой.
