# Дорожная карта RioTech Pro

## Реализовано в Android 0.5.4
- [x] Bluetooth Classic соединение с сопряжённым ELM327.
- [x] Базовая инициализация ELM327.
- [x] Чтение стандартных PID: RPM, скорость, температура ОЖ.
- [x] Чтение стандартных DTC Mode 03.
- [x] Очистка DTC Mode 04 с подтверждением пользователя.
- [x] Запрос VIN Mode 09 PID 02.
- [x] Определение поддерживаемых PID через Mode 01.
- [x] Запрос Calibration ID/CVN/ECU name через Mode 09 PID 04/06/0A.
- [x] Проверка файла BIN/HEX/MOT и SHA-256 (не проверка совместимости).\n- [x] Экспорт текущего диагностического экрана в текстовый отчёт.\n- [x] Общая нормализация нумерованных кадров ELM327 для OBD-II ответов.\n- [x] Исправлены переносы строк в отчёте поддерживаемых PID и ответе очистки кодов.

## Требует проверки на реальном автомобиле
- [ ] Совместимость конкретного ELM327 Bluetooth V1.5 и качество его реализации.
- [ ] Корректность чтения VIN и Mode 09 с несколькими CAN-кадрами.
- [ ] Точность обработки нескольких ответов, тайм-аутов и нестандартных заголовков.
- [ ] Реальные ответы поддерживаемых PID и DTC на Kia Rio III 2016 1.6 АКПП.
