# Rio3FlashPro

Диагностический проект для Kia Rio III. Цель — создать Android-приложение и Windows-клиент с честно обозначенной поддержкой адаптеров и безопасным разделением диагностики и программирования ЭБУ.

## Текущее состояние

- **Android:** базовая OBD-II диагностика через Bluetooth Classic ELM327: подключение к сопряжённому адаптеру, обороты, скорость, температура охлаждающей жидкости, чтение стандартных кодов неисправностей, запрос VIN через Mode 09 PID 02. Есть базовая проверка выбранного файла и вычисление SHA-256.
- **Windows:** WPF-клиент .NET 8; рабочее окно, базовая проверка BIN/HEX/MOT до 64 МБ, вычисление SHA-256 и экспорт текстового отчёта.
- **Автомобильный профиль:** Kia Rio III, 2016, 1.6, АКПП — по сведениям владельца.
- **Адаптер:** ELM327 Bluetooth имеется у владельца. Scanmatik 2 Pro/3 рассматривался как следующий профессиональный интерфейс, но ещё не приобретён/не проверен.
- **ЭБУ:** точная модель и аппаратно-программные идентификаторы пока не подтверждены. Запись в ЭБУ не реализована.

## Сборка

Android APK собирается workflow GitHub Actions: Actions → Build Android APK → скачать artifact `Rio3FlashPro-debug`.

Windows-клиент собирается workflow GitHub Actions: Actions → Build Windows Desktop. Для локальной сборки нужен .NET 8 SDK и Windows.

## Важные ограничения

ELM327 и стандартный OBD-II подходят для ограниченной диагностики двигателя, но не заменяют профессиональный интерфейс для чтения/записи памяти ЭБУ. Вычисление SHA-256 не подтверждает совместимость или корректность прошивки. Не записывайте неизвестные файлы в блок управления.

См. [дорожную карту](docs/ROADMAP.md) и [матрицу совместимости ЭБУ](docs/ECU_COMPATIBILITY.md).
