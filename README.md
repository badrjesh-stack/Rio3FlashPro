# RioTech Pro

Android-приложение для базовой диагностики Kia Rio III через Bluetooth Classic ELM327. Также в репозитории находится ограниченный Windows-клиент для проверки файлов.

## Android: функции версии 0.5.0

- Подключение к ранее сопряжённому Bluetooth ELM327.
- Инициализация ELM327 и автоматический выбор стандартного OBD-протокола.
- Чтение оборотов двигателя (PID 0C), скорости (0D), температуры охлаждающей жидкости (05).
- Чтение стандартных кодов неисправностей двигателя Mode 03.
- Очистка эмиссионных кодов Mode 04 только после отдельного подтверждения пользователя.
- Чтение VIN через Mode 09 PID 02, если это поддерживает ЭБУ.
- Запрос поддерживаемых стандартных PID (карта параметров).
- Запрос Calibration ID, CVN и названия ЭБУ через Mode 09 PID 04/06/0A, если поддерживается блоком.
- Проверка локального файла BIN/HEX/MOT и вычисление SHA-256 (до 64 МБ).

## Ограничения

- Это диагностическое приложение OBD-II, а не дилерский сканер Kia.
- ELM327 обычно не обеспечивает полноценную диагностику отдельного блока АКПП, ABS, SRS и фирменные сервисные функции. Для них нужен совместимый профессиональный интерфейс и подтверждённый протокол.
- Обучение дросселя, сброс адаптаций, сервисные процедуры ABS/АКПП не выполняются этой версией.
- SHA-256 только идентифицирует файл; он не проверяет его происхождение, совместимость, калибровки или контрольные суммы производителя.
- Запись, разблокировка и стирание памяти ЭБУ не реализованы намеренно. Нельзя включать эти функции без точного номера ЭБУ, документации, подходящего программатора и безопасного плана восстановления.
- Реальная работа с конкретным автомобилем зависит от адаптера, прошивки клона ELM327, протокола и поддержки PID самим ЭБУ. Нужна проверка на автомобиле.

## Сборка и загрузка APK

GitHub Actions → Build RioTech Pro Android APK → открой успешный запуск → Artifacts → RioTechPro-debug. В ZIP находится app-debug.apk.

Для установки новой версии поверх предыдущей сохраняется тот же applicationId и увеличивается versionCode.

## Windows

Windows WPF-клиент пока выполняет только базовую проверку BIN/HEX/MOT и экспорт текстового отчёта. Подключение автомобиля в Windows-клиенте не реализовано.

См. docs/ROADMAP.md, docs/ECU_COMPATIBILITY.md и docs/ECU_FLASHING_SAFETY.md.
